# Agent 协作

**简体中文** · [English](en/agent_selection.md) · [文档首页](../README.zh-CN.md#指南导航)

定义委派、隔离和回退；审查触发见 [engineering.md](engineering.md#independent-review-policy)，模型见 [model_profiles.md](model_profiles.md)。不授权，也不是调度器。

## 唯一 Root 与执行者

- 当前 Agent 是唯一 Root，保持模型，负责需求、架构取舍、任务拆分和最终验收；不另启 Root。
- Worker 执行限定工作并返回证据；启用不扩大授权。clone、安装 CLI 或模型可见不授权资料外发。
- 委派不授权安装、登录、增预算、改全局配置、提交/发布；不得绕过拒绝。

## 委派选择

- 按整项任务的不确定性、影响边界、错误代价和独立性选择，不按文件类型判断。
- 紧密关联的理解、设计和核心实现由 Root 连续完成；可独立验收的实质包再交匹配 Worker，Root 核验证据。
- 简单低风险且无需独立的工作可由 Root 完成；跨文件阅读不强制委派。
- 必需独立审查必须是新上下文的独立评估，Root 自审不能替代。
- 不拆碎或事后委派。默认一个 Worker；只并行独立工作，无写隔离则串行。

## 执行包与并行

- Root 提供目标、范围、排除项、契约、验收、目录、规则和交付格式并核验可达。
- 只传必要材料，不传对话或凭据；不假定上下文继承。
- 并行写用隔离副本/worktree；测试隔离端口、数据、进程、日志，不清理他方资源。
- Worker 不递归委派/启动 Root，不自行提交发布或改全局配置；契约变化交回 Root。
- 工具提示不等于 OS 沙箱；CLI 副作用仍受授权限制。

## 最小任务说明与结果

Worker 返回结论、改动、验证、未决项；标明 commit+diff 或快照/hash、环境、命令/结果/退出码、原始结果、验收项/缺口/版本。未知项标未知，敏感证据留在私有位置。

Root 核查关键路径和最终 diff；证据/版本变化时补查。记录实际 CLI/模型/推理；请求参数不证明已应用。

## 排队与可用性回退

- 区分不可见、入口缺失、鉴权/额度、拒绝、排队和慢响应。
- 原请求结束或确认取消后才替代；超时/无输出不证明停止。保留会话标识并查询，不重复执行。
- 每子任务最多两次可用性替代；选已授权可用者，不轮询或重复共同故障。
- 额度耗尽不重试；未核查不否定任何模型或入口，无凭据不试 DeepSeek。
- 替代用尽由 Root 执行；独立审查不可用则保留验收缺口。
- 回退不绕过权限、资料外发或预算；仅缺必要决定/能力时询问。

## 独立审查的执行

- Reviewer 用新上下文，只收问题、契约、补丁、验收、证据，不收作者推理/自评；不同模型不等于独立。
- 按模型表选 Reviewer；Root 复核发现并最终决定。
- 初审后仅因修复、版本变化或证据缺口复审；必要时续修并说明原因。最终版未复核不能标为通过，不机械重复已通过的审查。
- 审查不可用时继续自检并明示限制；用户接受风险时记录。

## 失败与升级

高风险或高不确定性任务可在已有授权内直接选择较高档位，不必先失败一次。执行失败先检查工具、范围、上下文和验证；仍有具体推理或质量瓶颈时才升级，说明原因和验收，不静默改用户设置。不强制逐级升级；每子任务最多两次质量升级，之后 Root 重判，两类上限不得互相绕过。

## CLI、权限与记录

只用已安装、配置、授权的入口；升级后核验参数。分别记录可见、请求成功、任务通过。不猜容量、token、费用或设置；记录留本机。

## 停止条件

达到验收即停止；保留缺口，不假称成功。
