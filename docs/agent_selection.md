本文件定义委派、交接、隔离与回退。风险与独立审查触发由 [engineering.md](engineering.md#independent-review-policy) 定义，模型偏好见 [model_profiles.md](model_profiles.md)。本文件不是调度器，也不授予新的权限。

## 唯一 Root 与执行者

- 当前用户打开的 Agent 是唯一 Root，负责需求、架构取舍、任务拆分和最终验收；保持当前模型，不启动另一个 Root。
- Worker 执行限定调查、实现、测试、文档整理和审查，提供可定位证据。
- 使用者明确启用的执行者可在既有授权内持续工作。clone 仓库、安装 CLI 或模型可见不等于允许向服务发送项目资料。
- 委派不授予安装、登录、增加预算、修改全局配置、提交或发布的额外权限；不能通过更换模型或关闭审批绕过拒绝。

## 委派选择

根据整项任务的规模、风险和独立性决定，不按文件数量或动作次数机械触发。

- 可形成完整执行包的实质调查、实现或成套验证，优先交给匹配职责的 Worker；Root 处理决策与证据核验。
- 简单、低风险、边界清楚且无独立性需求的工作可由 Root 完成；跨文件阅读本身不是强制委派条件。
- 规则要求的独立审查必须使用新上下文的独立评估，不能以 Root 自审替代。
- 不为展示协作拆碎任务，不在 Root 做完整项工作后补形式化委派。只有可独立推进且有实际收益时并行。
- 默认一个 Worker；数量受宿主上限和隔离能力约束。无可靠写入隔离时串行执行。

## 执行包与并行

- Root 提供目标、文件范围、排除项、已接受契约、验收场景和交付方式。紧密相关的调查、实现、自测可由同一 Worker 连续执行。
- 提供工作目录、适用规则入口并核验可达性；不假定原生 Agent、CLI 或远程执行者继承同一上下文。只传必要材料，不传整段对话或凭据。
- 并行写入使用隔离副本或 worktree；测试还需隔离端口、数据、进程和日志。不得清理其他任务资源。
- Worker 不递归委派、不启动 Root、不自行 commit/push/merge、不修改全局配置。新证据要求改变契约时交回 Root 决策。
- 工具权限和只读提示不等于 OS 沙箱；外部 CLI 的文件、shell、网络和日志副作用仍受授权约束。

## 最小任务说明与结果

Worker 返回结论、改动位置、实际验证和未解决问题。

| 内容 | 最小要求 |
| --- | --- |
| 对象 | 提交及未提交差异，或快照/hash；必要环境版本 |
| 执行 | 实际命令、结果、退出码与环境；未知字段明确标注 |
| 原始结果 | 可定位报告或日志；敏感证据留在私有位置 |
| 验收关联 | 对应验收项、缺口、限制及所审版本 |

Root 核查关键路径和最终 diff，复用足够证据；缺失、冲突、版本变化或风险需要时补充检查。报告实际 CLI/模型与推理设置，不把请求参数当作服务端已生效的证明。

## 排队与可用性回退

- 区分模型不可见、入口缺失、鉴权/额度失败、权限拒绝、明确排队和普通慢响应。
- 原请求已结束或确认取消后才替代；超时与无输出不能证明后台停止。无法确认时保留会话标识并查询，不重复执行。
- 按任务职责选择已授权、可用的替代执行者，不固定轮询全部模型。每项子任务最多两次可用性替代；共同故障不做无意义请求。
- 额度耗尽不重试同一入口；Spark CLI 独立于原生模型菜单，未核查不能声称不支持。无凭据的 DeepSeek 不试探调用。
- 替代用尽后，由有能力的 Root 继续普通执行；所需独立审查不可用时保留验收缺口，不冒称完整验收。
- 不借回退绕过权限、资料外发或预算限制。只有必要权限、决策或不可替代能力缺失时请求输入。

## 独立审查的执行

- Reviewer 使用新上下文，获得问题、契约、补丁、验收条件与实际证据，不传作者推理或自我评价。不同模型不是独立性的充分条件。
- 按模型表选用 Astra / low 或符合条件的替代审查者；Root 复核重要发现并保留最终决定。
- 默认初审与修复后复审两轮；仍有问题继续必要修复，追加复核说明范围和理由。未复核的最终版本不能标为通过。
- 独立审查不可用时继续有用自检，明确限制；用户接受残余风险时记录例外。

## 失败与升级

先解决工具、范围、上下文和验证前提。有具体质量不足证据时才调整模型或推理强度，不静默改变用户指定设置。每次升级说明原因与验收要求，同一子任务最多两次，之后 Root 重判。质量升级与可用性回退不能互相绕过上限。

## CLI、权限与记录

只使用已安装、已配置、已授权入口。升级后按帮助核验参数；模型清单可见、请求成功、任务通过分别记录。不猜测上下文容量。运行记录与用量留在本机，未知 token、费用或设置写未知。

## 停止条件

达到验收即停止，不为增加 Worker 延长任务。保留必要缺口，不假称取消、配置或验证成功。
