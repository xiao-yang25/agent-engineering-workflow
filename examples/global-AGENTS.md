# 本机 Agent 工程入口

使用前将 `<WORKFLOW_REPO>` 替换为 clone 后仓库的绝对路径；这是人工替换标记，不是自动展开变量。将本文合并到 `~/.codex/AGENTS.md`，保留原有个人规则。

若自定义了 `CODEX_HOME`，合并到该目录下的 `AGENTS.md`。只在仓库外的副本填写本机信息，共享指南正文直接引用原仓库；无需复制或修改整套指南。

共享指南：`<WORKFLOW_REPO>`。

- 开始任务时读取 `<WORKFLOW_REPO>/AGENTS.md`，再按任务路由读取必要指南。嵌套引用相对于该指南所在目录解析，不相对于业务项目或本文件解析。
- 当前 Root 保持当前模型，负责架构取舍与最终验收。
- 个人执行者启用清单：由使用者填写；启用时明确资料范围、服务和预算边界。默认模板不授权外发项目资料。
- 尚未选用额外执行者时，普通任务由当前 Root 完成；所需独立审查缺少可用执行者时明确保留验收缺口，不将自审当作独立审查。
- 默认模型偏好见 `<WORKFLOW_REPO>/docs/model_profiles.md`，委派机制见 `<WORKFLOW_REPO>/docs/agent_selection.md`。个人覆盖在此处记录，不改公开模板中的账号状态。
- Skill 仅按用户显式请求启用，除非更高优先级指令要求。
- 私有审视日志：由使用者选择仓库外位置；可从 `<WORKFLOW_REPO>/examples/workflow_evolution_log.md` 复制空白模板。未配置调度时不声称已启用。
- 不在本文保存 API Key。入口不可达时报告具体缺口，继续不依赖该入口的工作。
