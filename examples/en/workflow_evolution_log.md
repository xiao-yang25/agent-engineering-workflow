# Workflow review log template

[简体中文](../workflow_evolution_log.md) · **English** · [Documentation](../../README.md#guides)

This file is a blank template, not a place for personal history, task identifiers, or local scheduling state. Copy it to a private location outside the repository and record that location in the local global entry. See [workflow improvement](../../docs/en/workflow_evolution.md) for the rules.

Copy only the Markdown block below and replace `<WORKFLOW_REPO>` with the shared repository’s absolute path. Verify the rule entry before use; keep repository navigation out of the private instance.

## Issue index

Each record includes the date, task or evidence identifier, file version or hash, issue, change location, before/diff reference, actual checks and results, decision, and next step. Keep original evidence in permitted private task records. Label unknowns explicitly and never invent passing results.

## Real-task regression index (fill in the private instance)

No cases are registered; the fields below are blank. Reference original task evidence without copying source text. Issue records reference case IDs rather than creating a separate ledger.

- Inputs/prerequisites, expected outcome, acceptance entry point, and applicability limits: not recorded.
- Before baseline, after version, model/environment, and comparability limits: not recorded.
