# 工作流审视日志模板

**简体中文** · [English](en/workflow_evolution_log.md) · [文档首页](../README.zh-CN.md#指南导航)

本文件只提供空白模板，不保存个人历史、任务标识或本机调度状态。复制到仓库外的私有位置后使用；本机全局入口记录该位置。规则见 [工作流自迭代](../docs/workflow_evolution.md)。

仅复制下方 Markdown 块，将 `<WORKFLOW_REPO>` 替换为共享仓库绝对路径；核对规则入口后使用，上方仓库导航不进入私有实例。

```markdown
# 工作流审视日志

规则入口：`<WORKFLOW_REPO>/docs/workflow_evolution.md`。

## 当前审视游标

- 最近审视：未执行。
- 实际覆盖：未登记。
- 调度：未配置；文档存在不代表自动化已启用。
- 验证与限制：未验证。
- 下一步：首次审视时登记允许访问的范围。

## 问题索引

每条记录包含日期、任务或证据标识、文件版本或 hash、问题、变更位置、before/diff 入口、实际检查及结果、决定和下一步。原始证据保留在允许的私有任务记录中；未知项明确标注，不编造通过结果。

## 真实任务回归索引（私有实例填写）

样例尚未登记；以下为空白字段。填写时引用原任务证据，不复制原文；同一问题记录引用样例标识，不另建台账。

- 样例标识、失败/成功类型、来源与证据版本：未登记。
- 输入/前提、预期结果、验收入口、适用边界：未登记。
- 改动前基线、改动后版本、模型/环境与可比性限制：未登记。
- 预定重复次数、全部实际尝试及最终状态证据索引：未执行。
- 保留/修正/撤回/观察中、理由与下一步：未决定。
```
